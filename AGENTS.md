Preserve frozen sources and evidence byte-for-byte. New calculations require their own source and result identities. Do not weaken an acceptance gate to make an exported study pass.

Run `scripts/verify.sh` for repository changes. Match any additional computation to the actual scientific claim; the large graph enumerations and external chemistry datasets are not default smoke checks.

The exact thermodynamic kernel is minimal and non-adaptive: empty Ruby, absent Opal, one-state memory. Apply its independent T1–T6 boundary. A richer learning Xypher has additional architectural requirements.

THAIM is the one-sided positive receipt. Ξ retains both positive and negative entropy changes and the stored-energy change. α is independently grounded, not a fitted reward parameter. Preserve legacy identifiers in frozen artifacts.

Never commit environment files, keys, build outputs, licensed source tables excluded by the packet, or raw external datasets. Keep existing third-party attribution and license notices.
