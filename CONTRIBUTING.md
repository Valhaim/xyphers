# Working on Xyphers

Start with one claim, its article, and its executable evidence. Keep the question understandable without requiring the reader to know the rest of the project.

Run `./scripts/verify.sh` before proposing a change. For a scientific change, also run the relevant study's own controls and record the exact source, inputs, command, and result.

## Preserve the scientific record

Files covered by `SOURCE-SHA256SUMS` and evidence `SHA256SUMS` are frozen records. Improve explanations around them. Put changed calculations in a new version with new provenance, and retain the earlier result.

The exact thermodynamics result is closed within its declared boundary. Independent reproduction and concrete defects are welcome. A new ambition does not reopen the existence result or make the minimal kernel responsible for demonstrating learning, chemistry, or an economy.

Use **Graph Substrate**, **Thermodynamic Harness**, **Praxion**, and **THAIM** in new prose. Keep endpoint entropy distinct from complete path entropy. Compute signed changes before clipping positive receipts. Ground any claimed α independently, then test the same α through contact.

## Implementations

Prefer Futuruna for new Xypher domain logic and Rust for core infrastructure and independent verifiers. The molecular Rust code here is a frozen experimental implementation. Teaching examples should call it and label their inputs and perspective.

Keep claim, code, input provenance, and reproduction instructions together. Introduce a concept before its symbol. Link to the website explanation and to a particular evidence revision when publishing an article.

The website is the primary reading edition. The portable articles here use GitHub-compatible equations, local evidence links, and viewing links in place of embedded video. Keep their prose and scientific claims aligned when revising an article, and update the article-to-evidence map in [research/README.md](research/README.md). Mark a website route live only after checking that it is published. Reference executable evidence by an immutable commit so a later code change does not silently change an article's experiment.
