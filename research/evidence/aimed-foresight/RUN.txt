XYPHERS AIMED FORESIGHT REPRODUCTION

The verifier needs only a Rust toolchain. It has no external dependencies.
In a release build the test takes a few seconds and the run about eight
minutes.

From source/xypher-aimed-foresight-proof/:

  cargo test --release --locked
  cargo run --release --locked --quiet

The test solves the primary world and checks that every gate passes there
and that all seven controls fail first where the boundary says. The report
is 91 lines. It lists the gates G01-G11, the controls C01-C07 with where
each failed, one line per world and agent with the exact open future held
(H), fuel flow (J), yield (Y), mean bridge density (rho), the warming
rival's rate (s*), the edge at equal power (E), and the certified
efficiency and yield bound, then the five hypothesis verdicts, and ends:

  OVERALL PASS

To compare the whole report with the recorded run:

  cargo run --release --locked --quiet | diff ../../expected-report.txt -

No output from diff means your run reproduced the recorded report exactly.
Its SHA-256 is

  aee1f946132ce560e1b87d9dbeae9c190635ac4ea2531b66bb2720c93c03b511

The independent check needs only Python 3. With python-flint installed it
takes about ten seconds; with the standard library alone it takes one to
two hours. From this directory:

  python3 independent_check.py expected-report.txt

It prints one line per world and agent, then

  H and J agree with the frozen report in 66 of 66 steady states

and the five verdicts, as in expected-independent-check.txt.

The Futuruna declaration can be checked with the Futuruna compiler:

  runa check xypher.runa

Reproduction boundary
  This is an exact replay of a frozen finite construction. A passing replay
  reproduces the recorded result; the scope is the one stated in README.txt.
