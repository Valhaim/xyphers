XYPHERS CONTROL INFORMATION REPRODUCTION

The verifier needs only a Rust toolchain. It has no external dependencies
and runs in about twenty seconds in a debug build.

From source/xypher-control-information-proof/:

  cargo test --locked
  cargo run --locked --quiet

The test checks that the report has fourteen gates and nine controls in
order and that the run succeeds. The report is 41 lines. It lists the gates
G01-G14, the controls C01-C09 with where each failed, one witness line per
arrangement of the primary archipelago with its exchange constants, one
instrument line, one line for each of the seven family cases, and ends:

  OVERALL PASS

To compare the whole report with the recorded run:

  cargo run --locked --quiet | diff ../../expected-report.txt -

No output from diff means your run reproduced the recorded report exactly. Its SHA-256 is

  ca303e0db354dbd17d71381efc6fb0a4a814fabfba041a8ce5185263217be7e9

The Futuruna construction can be checked with the Futuruna compiler:

  runa check xypher.runa

Reproduction boundary
  This is an exact replay of a frozen finite construction. A passing replay
  reproduces the recorded result; the scope is the one stated in README.txt.
