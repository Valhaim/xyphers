# Downloadable evidence

These are the same portable, checksummed archives linked from the research articles. Keep each `.zip` beside its `.zip.sha256` file and verify it with:

```bash
shasum -a 256 -c <archive-name>.zip.sha256
```

The browsable source copies live in [`../evidence/`](../evidence/). The minimal thermodynamic verifier also has an unpacked copy in [`../code/xypher-thermodynamics-proof/`](../code/xypher-thermodynamics-proof/).
